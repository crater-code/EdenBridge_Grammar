TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

Problem: Form submits but no data in database
Solution:
  1. Check browser console (F12) for errors
  2. Visit test-connection.php
  3. Check api/error.log file on server
  4. Verify api folder is at public_html/api/

Problem: 404 error on form submit
Solution:
  1. Make sure api folder uploaded correctly
  2. Check .htaccess file in api folder
  3. Verify file permissions (755 for folders, 644 for files)

Problem: Database connection failed
Solution:
  1. Verify database exists in cPanel
  2. Check database credentials in config.php
  3. Make sure database user has permissions
  4. Try test-connection.php

Problem: Tables not found
Solution:
  1. Import database.sql again
  2. Make sure you selected correct database
  3. Check if import completed successfully
